# Mulewa Academy Football Club

Static website for Mulewa Academy Football Club, Meanwood, Waterfalls, Lusaka.

- `index.html` – the whole site (no build step)
- `assets/` – logo, favicon, tournament flyer and action photo

## Run locally
Open `index.html` in a browser.

## Deploy
Hosted on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## To update
